# Maverick Shift

O **Maverick Shift** é um projeto acadêmico desenvolvido para auxiliar a gestão da estética automotiva **El Possante**.

A proposta é criar uma aplicação web que centralize as informações do negócio e facilite as atividades diárias da equipe.

## Objetivo

Desenvolver um sistema para controlar clientes, veículos, produtos, serviços, agendamentos, ordens de serviço e movimentações financeiras.

## Funcionalidades planejadas

- Autenticação de usuários;
- Controle de acesso para administrador e funcionário;
- Cadastro de clientes e veículos;
- Controle de produtos e estoque;
- Cadastro de serviços;
- Gerenciamento de agendamentos;
- Controle de ordens de serviço;
- Registro de gastos e pagamentos;
- Geração de relatórios financeiros.

## Tecnologias

- Java;
- Spring Boot;
- JPA;
- Aplicação web multiplataforma.

Outras tecnologias poderão ser adicionadas durante o desenvolvimento.

## Status do projeto

O projeto está em fase inicial, com foco no levantamento de requisitos, criação das histórias de usuário e análise do sistema.

A previsão de conclusão é dezembro de 2026.

## Estrutura do repositório

- `1.Requisitos`: requisitos, casos de uso e protótipos;
- `2.Analise e Design`: modelos e documentos de análise;
- `3.Implementacao`: código-fonte;
- `4.Teste`: documentação e resultados dos testes;
- `5.Implantação`: arquivos de implantação;
- `6.Gerenciamento de Projeto`: atas e documentos de acompanhamento.
